What you're watching

Keys hash onto a consistent hash ring (this is the actual FNV-1a + avalanche hash from the C++ code, compiled to JS). Each key is owned by one node and replicated to its successor. Any node accepts any request and forwards it to the owner; the owner applies the write, acks immediately, and a background sender replicates asynchronously. Kill a node and the ring re-converges: reads keep working from replicas, and the restarted node heals via SYNC.
